# COOL Radio 0.4.0

中文网络电台 [cooltv.top](https://cooltv.top) 的电脑版。

| 系统 | 下载 |
| --- | --- |
| Mac（Apple 芯片 / Intel） | [COOL-Radio-mac.dmg](https://github.com/goolguy007/cooltv-app/raw/main/COOL-Radio-mac.dmg) |
| Windows 10 / 11 | [COOL-Radio-windows.exe](https://github.com/goolguy007/cooltv-app/raw/main/COOL-Radio-windows.exe) |
| 安卓 7.0 及以上 | [COOL-Radio-android.apk](https://github.com/goolguy007/cooltv-app/raw/main/COOL-Radio-android.apk) |

国内下载更快的地址：https://cooltv.top/app/

**Mac**：打开 dmg，把 COOL Radio 拖进「应用程序」。第一次打开若提示无法验证开发者，到「系统设置 → 隐私与安全性」最下面点「仍要打开」。

**Windows**：运行安装程序。若提示「Windows 已保护你的电脑」，点「更多信息 → 仍要运行」。

**安卓**：下载后点开安装。若提示「禁止安装未知应用」，按提示允许浏览器安装应用即可。
